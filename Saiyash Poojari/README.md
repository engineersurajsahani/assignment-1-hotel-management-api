# Hotel Booking API

A beginner-friendly backend REST API built with **Node.js** and **Express.js**. This project demonstrates how a backend server receives HTTP requests, processes JSON data, manages users, handles login, and provides hotel-related API endpoints.

##  Features

- Express.js backend server
- User registration API
- User login API
- Hotel creation API
- Get all hotels API
- JSON request and response handling
- HTTP status codes
- API testing using Postman
- Local development using Node.js

##  Tech Stack

- **Node.js** — JavaScript runtime
- **Express.js** — Backend web framework
- **JavaScript** — Server-side programming
- **Postman** — API testing
- **JSON** — Data exchange format
