# Hotel Management API

A REST API for managing hotel information using Node.js and Express.js.

## Features

- User registration
- User login
- Add a hotel
- Get all hotels
- Get a hotel by ID
- Update hotel details
- Delete a hotel
- Error handling
- JSON request and response handling
- Request logging

## Technologies Used

- Node.js
- Express.js
- JavaScript
- bcryptjs
